🧩 Agent Skill（智能体技能）

阅读本页约 60 秒 · 文末有 4 道测试题

一句话定义：Agent Skill 是给 AI 智能体安装的"可插拔专业能力包"——一个包含 SKILL.md 说明书的文件夹，智能体在任务需要时自动加载对应技能。

1运行机制（记住这张流程就懂了）

用户提出任务→ 智能体按语义匹配 Skill 的 description→ 按需加载 SKILL.md→ 按技能指导执行任务

💡 关键：技能平时不占用上下文，命中才加载——这叫渐进式加载（Progressive Disclosure），省 token 又专业。

2Skill 的结构：一个文件夹 + 一份说明书

# 技能文件夹结构
my-skill/
├── SKILL.md          # 核心：元数据 + 操作指导
├── scripts/          # 可选：可执行脚本
└── references/       # 可选：参考资料

# SKILL.md 的头部（YAML frontmatter）
---
name: pdf-export          # 技能名
description: 当用户要求导出 PDF 时使用  # ⭐ 触发开关，最重要
---
正文：逐步操作方法、命令、注意事项…

3为什么需要 Skill？

  • 沉淀专家经验：把"会做某事的人的方法"变成可复用资产，智能体不用每次从零摸索
  • 按需扩展：智能体本体不变，装一个技能就多一项专长（像手机装 App）
  • 一致性：同一个任务，每次都按同一套最佳实践执行

✅ 随堂测试（点选项立刻判分）

Q1. Agent Skill 最核心的文件是？

✔ SKILL.md 是技能的"说明书"：头部声明 name 和 description，正文写操作方法。

Q2. 技能什么时候被加载进智能体？

✔ 渐进式加载：只在 description 与任务匹配时加载，节省上下文与 token。

Q3. SKILL.md 头部哪个字段直接决定技能是否被触发？

✔ description 是"触发开关"——写清楚"什么时候用"，智能体才能正确匹配。

Q4. Skill 与 MCP 工具的主要区别是？

✔ Skill 是方法论/SOP，MCP 是外部系统连接器，两者常配合使用。
