## Git 基本概念

- **clone**：把远程仓库复制到本地
- **add**：把修改的文件放入暂存区
- **commit**：把暂存区内容提交为一次版本记录
- **push**：把本地提交推送到远程仓库

## 常用命令

```bash
git clone <仓库地址>          # 克隆远程仓库
git add .                     # 暂存所有修改
git commit -m "提交说明"       # 提交到本地仓库
git push -u origin main       # 推送到 GitHub
```
