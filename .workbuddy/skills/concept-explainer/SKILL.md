# 概念学习资料生成器（concept-explainer）

把"学会一个概念"变成一条标准化流水线：核实资料 → 结构化 → 生成单页 HTML → 标注来源 → 自检。
本 Skill 生成的内容保存在本仓库 `learning-materials/` 目录下，长期积累形成个人概念知识库。

## 一、适用场景

- 用户说"我想学 XX""帮我讲讲 XX""XX 是什么，1 分钟掌握"等，且 XX 是一个明确的概念
- 用户要求为课程仓库补充某个概念的学习资料
- 不适用于：开放式咨询、多个松散问题的混合、非知识型任务

## 二、输入信息

| 输入 | 必需 | 说明 |
|------|------|------|
| 概念名称 | ✅ | 如"Agent""大模型的上下文"；中文概念需给出对应英文术语用于命名 |
| 学习者背景 | 可选 | 缺省按"初学者+正在上大数据与人工智能课程"处理 |
| 输出文件名 | 可选 | 缺省用概念的英文小写连字符形式，如 `llm-context.html` |

## 三、生成步骤

1. **研究核实**：先用联网搜索/网页抓取查证概念定义，优先官方文档、论文、权威工程博客；无法核实的说法不得写入
2. **结构化**：把内容归入下方"输出结构"的五个固定板块，提炼成初学者能读懂的语言
3. **生成 HTML**：按仓库 `learning-materials/` 中现有页面的卡片式风格生成单页文件（浅色主题、无外部依赖、可离线打开），放入 `learning-materials/<概念>.html`
4. **标注来源**：每个板块引用的说法都要能对应到"来源"板块中的链接；标注链接的核查日期
5. **自检**：按下方"自检要求"逐项检查后，再向用户交付
6. **更新索引**：在仓库 `README.md` 的"学习资料"列表中追加新文件

## 四、输出结构（五个固定板块）

1. **个人解释**：用学习者视角、打比方的方式重新表述概念（不是定义的复述），3~5 句话
2. **核心机制 / 组成**：概念的关键原理、组成部分或运行流程，可用列表/表格/图
3. **具体应用场景**：至少一个真实场景，优先结合学习者自己的项目经历
4. **易混淆问题 / 使用边界**：与相似概念的辨析、常见的错误理解、什么情况下不适用
5. **可核查的资料来源**：官方文档 / 论文 / 权威博客链接列表，每条附一句话说明与核查日期

## 五、资料来源要求

- 优先级：官方文档 > 论文（arXiv 等）> 权威工程博客 > 教程网站；论坛帖子与自媒体不作为依据
- 每个概念至少 2 个来源，且必须在生成前实际访问核实（用网页抓取工具），不得凭记忆写链接
- 来源必须标注：标题 + 作者/组织 + 链接 + 核查日期；无法访问的链接要注明原因或替换
- 不同来源说法冲突时，如实标注分歧，不擅自取舍

## 六、自检要求（交付前逐项打勾）

- [ ] 五个板块齐全，无缺漏
- [ ] "个人解释"是自己的话，不是定义照抄
- [ ] 每个关键论断都能追溯到"来源"板块中的某条链接
- [ ] 所有链接已实际访问核实，并标注核查日期
- [ ] HTML 无外部依赖，浅色主题，文件名符合 `<概念英文名>.html`
- [ ] 与 `learning-materials/` 中其他资料风格一致
- [ ] README 的资料列表已同步更新
- [ ] 向用户说明哪些内容是 AI 生成、哪些建议人工复核
