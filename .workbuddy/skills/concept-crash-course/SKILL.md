# 概念速成卡片生成器（concept-crash-course）

把一个"想学会的概念"变成一张**能反复玩的单页学习卡**：先核实资料，再写成大白话，最后配上闯关测试检验是否真懂。
产出统一保存在本仓库 `learning-materials/<概念英文名>.html`。

## 一、适用场景

- 用户说"我想学 XX""XX 是什么""帮我讲讲 XX""一分钟搞懂 XX"，且 XX 是单一明确概念
- 本仓库课程作业：为 Agent、大模型上下文、Agent Skill 等概念生成学习资料
- **不适用**：开放性咨询、多个概念混问、非知识型任务、要求写代码的请求

## 二、输入信息

| 输入 | 必需 | 说明 |
|------|------|------|
| 概念名称 | ✅ | 中文概念需给出对应英文术语，用于文件名，如"大模型的上下文"→ `llm-context.html` |
| 学习者背景 | 可选 | 缺省按"初学者 + 正在上大数据与人工智能课程"处理 |
| 输出文件名 | 可选 | 缺省为概念英文小写连字符形式 |

## 三、生成步骤

1. **核实资料**：联网搜索并实际访问来源页面（官方文档 / 论文 / 权威博客），记下要点与链接
2. **提炼大白话**：把概念改写成初学者能懂的话，并配一个生活化类比（奶茶店、厨房、快递站等真实场景）
3. **整理核心要点**：归纳成 3~5 条，每条一句话讲清"是什么/怎么用"，避免堆术语
4. **生成 HTML**：按下方输出结构生成单页文件，保存到 `learning-materials/<概念英文名>.html`
5. **自检并交付**：按自检清单逐项检查后，同步更新仓库 README 的资料列表与进度

## 四、输出结构（HTML 五个板块）

1. **一句话理解**（高亮卡）：一句话定义 + 一个生活例子的类比段落
2. **核心要点**：3~5 条要点列表，每条加粗关键词
3. **资料来源**：至少 3 条链接，每条注明"标题 / 作者或组织 / 链接 / 核查日期"，并说明该来源支撑了哪个论断
4. **闯关测试**：两关共 6 题
   - 第一关基础 3 题 → 全对升级第二关
   - 第二关进阶 3 题 → 全对通关，显示 🏆 与"再玩一次"按钮
   - 答错：显示正确/错误标记 + **逐选项解析**（为什么对、为什么错），第二关答错降回第一关，第一关答错回到本关第一题
   - 顶部显示关卡进度条（第一关 / 第二关 / 通关）
5. **页脚**：注明"AI 生成初稿 + 人工核查"，以及文件在仓库中的路径

### 页面样式约定

- 浅色卡片风：白底卡片 + 圆角 + 淡阴影，主色 `#ea580c`（橙）
- 单文件、内联 CSS/JS、**无外部依赖**（不引 CDN），可离线双击打开
- 移动端可读（`max-width: 860px` + `viewport`）

## 五、资料来源要求

- 优先级：官方文档 > 论文（arXiv 等）> 权威工程博客 > 教程站；论坛与自媒体不作为依据
- **每个概念至少 3 个来源**，且生成前必须实际访问确认可访问，不得凭记忆写链接
- 每条来源标注：标题 + 组织/作者 + 链接 + 核查日期；无法访问的要替换或明确标注
- 来源说法冲突时如实标注分歧，不擅自取舍

## 六、自检要求（交付前逐项打勾）

- [ ] 五个板块齐全（一句话理解 / 核心要点 / 来源 / 闯关测试 / 页脚）
- [ ] 用了生活化类比，不是定义照抄
- [ ] 来源 ≥ 3 条，全部实际访问过并标注核查日期
- [ ] 每个关键论断都能对应到某条来源
- [ ] 闯关逻辑正确：升级 / 降级 / 通关 / 再玩一次（可用 Node 模拟浏览器跑一遍验证）
- [ ] HTML 无外部依赖、浅色主题、文件名规范
- [ ] README 的资料列表与进度清单已同步更新
- [ ] 向用户说明：哪些是 AI 生成、哪些建议人工复核
