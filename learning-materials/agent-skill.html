🧩 Agent Skill（智能体技能）

阅读约 1 分钟 · 下方有两关共 6 道闯关题 · 生成日期 2026-09-08

☕ 一句话理解

Agent Skill 就是给 AI 助手配的一张"SOP 操作卡"：一个文件夹，里面一份 SKILL.md 说明书（开头写清"什么时候用我"，正文写"照这几步做"），AI 接到对口的活儿时才抽出来照做。

生活例子 🧋：奶茶店来了个万能新店员（AI 助手）。老师傅把"珍珠怎么煮、奶盖怎么打"写成一张张操作卡贴在卡墙上，每张卡的标签写着"什么单子用我"。接到订单，店员扫一眼标签——对上"珍珠奶茶"就抽出那张卡照着做。平时卡片收在抽屉里，不占台面；有了卡片，新店员不用每次重新学，出品永远一个味。

1四个核心要点

  • 它是什么：一个文件夹 + SKILL.md 说明书（YAML 头部写 name 和 description，正文写操作步骤），可附带脚本和参考资料
  • 怎么触发：AI 拿你的任务和每张卡的 description 做"对号入座"，匹配上才加载——这叫渐进式加载：平时只占一行字，用时才展开，省钱又不占"脑容量"
  • 有什么用：把"会做某件事的方法"沉淀成资产——一次编写、每次复用、输出质量稳定；相当于给 AI 装专业外挂
  • 别搞混：Skill 管"怎么做"（SOP 手册），MCP 管"连得上"（USB 外设），RAG 管"查什么"（资料柜）——三个互补，不是竞品
